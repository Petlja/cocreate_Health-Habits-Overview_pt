# Tabelas Dinâmicas

A tabela dinâmica é uma das ferramentas mais importantes para análise de dados em programas como o *Microsoft Excel* e o *Google Sheets*. Ela permite "girar" (pivot = girar) os mesmos dados e apresentá-los de uma nova forma — agrupá-los, contá-los, calcular médias ou comparar categorias, sem alterar a tabela original. Em vez de contar manualmente e criar várias tabelas auxiliares, a tabela dinâmica permite obter respostas de forma rápida, precisa e organizada.

```{infonote}
No basquetebol, o pivot é o jogador que mantém um pé fixo no chão e, rodando o corpo, pode passar a bola em diferentes direções. De forma semelhante, a tabela dinâmica usa os mesmos dados, mas "gira-os" e reorganiza-os para que possamos observá-los de diferentes ângulos, consoante o que queremos descobrir.
```

## Diferença entre uma tabela simples e uma tabela dinâmica

Numa tabela simples podemos ver cada venda individual, mas se quisermos saber, por exemplo, a quantidade total de cada tipo de fruta vendida, teríamos de encontrar manualmente todas as linhas com maçãs e somar as quantidades, depois bananas, depois laranjas… Com um grande número de linhas, isso demora tempo e é fácil cometer erros.

**A tabela dinâmica organiza e soma os dados automaticamente.** Por exemplo:

![Tabela dinâmica - venda de frutas](images/table3_sr.png)

Esta apresentação permite ver os resultados imediatamente, sem somar manualmente e sem fórmulas.

```{infonote}
A tabela simples apresenta dados individuais. A tabela dinâmica apresenta uma visão geral e permite a análise.
```
