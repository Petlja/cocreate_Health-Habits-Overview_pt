# Tabelas Dinâmicas

A tabela dinâmica é uma das ferramentas mais importantes para análise de dados em programas como o *Microsoft Excel* e o *Google Sheets*. Ela permite "girar" (pivot = girar) os mesmos dados e organizá-los de diferentes perspectivas, dependendo do que queremos descobrir.

```{infonote}
No basquetebol, o pivot é o jogador que mantém um pé fixo no chão e, rodando o corpo, pode passar a bola em diferentes direções. De forma semelhante, a tabela dinâmica usa os mesmos dados, mas os "gira" e reorganiza para que possamos vê-los de diferentes ângulos, dependendo do que queremos aprender.
```
Uma funcionária de uma frutaria registra diariamente cada venda numa tabela. Para cada compra, anotou os seguintes dados:

![Tabela - venda de frutas](images/table2_sr.png)

Estes são dados brutos. A partir deles, não podemos obter imediatamente a resposta a perguntas como *Qual fruta se vende mais?* ou *Os clientes pagam mais frequentemente em dinheiro ou com cartão?*

## Diferença entre uma tabela simples e uma tabela dinâmica

Numa tabela simples podemos ver cada venda individual, mas se quisermos saber, por exemplo, a quantidade total de cada tipo de fruta vendida, teríamos de encontrar manualmente todas as linhas com maçãs e somá-las, depois bananas, depois laranjas... Com um número maior de linhas, isto leva tempo e é fácil cometer erros.

**A tabela dinâmica organiza e soma os dados automaticamente.** Por exemplo:

![Tabela dinâmica - venda de frutas](images/table3_sr.png)

Esta apresentação permite ver os resultados imediatamente, sem somar manualmente e sem fórmulas.

```{infonote}
A tabela simples apresenta dados individuais. A tabela dinâmica apresenta uma visão geral e permite a análise.
```
